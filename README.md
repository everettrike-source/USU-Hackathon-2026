# AI Meal Planner (USU Hackathon Project)

An AI-powered meal planner built in 24 hours by a team of three for the USU Hackathon. This app simplifies achieving weight goals by generating personalized daily meal plans based on your body metrics and timeline.

## Features
* **Personalized Calorie Targets:** Calculates daily caloric needs based on height, weight, age, sex, activity level/intensity, target weight, and your timeframe to hit that goal.
* **AI Meal Generation:** Uses the Gemini API to generate 3 customized meals and snacks per day that fit your daily calorie goals and any specific dietary restrictions.
* **Modern Frontend:** Developed entirely over a 24-hour period using a modern web stack.

## Tech Stack
* React
* TypeScript
* Vite
* Gemini API

## How to Run
* Clone the repository and open the folder in **VS Code**.
* Open the VS Code terminal.
* Run `npm install` to install the project dependencies.
* Run `npm run dev` to start the Vite local development server.

## Project Status & Known Issues
**Note:** Because this was a 24-hour hackathon project, it is currently not being actively maintained. The Gemini API key required to fetch the meal plans is currently not set up or included in the repository. To run the full meal generation feature locally, you will need to configure your own Gemini API key.
